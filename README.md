# Plano de las embajadas de Madrid, 1936: archivos

Archivos del plano que se ve en https://zurbano21.com/plano-embajadas, servidos por GitHub Pages:
los trozos del plano parcelario 1:500 (1929-1940) redibujado en vectores (`vec/`, gzip) y los recortes
del escaneo original de cada edificio (`recortes/`). Las hojas originales son los «Catastrones 1940-1950»
del Geoportal del Ayuntamiento de Madrid.

Este repositorio lo genera `scripts/export_web.py` y se reescribe entero en cada exportación: no se edita a mano.
